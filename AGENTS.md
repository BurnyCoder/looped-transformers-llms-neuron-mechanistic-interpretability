# AGENTS.md — notes for coding agents working on this repo

- Entry point: `run_pipeline.py`. It calls named phases from `src/loopneuron/`. Keep phase functions thin, and keep the logic in modules.
- Model: `ByteDance/Ouro-1.4B`, revision pinned in `.env`.
  - Always load it through `loopneuron.model.load_model`. That function sets `model.early_exit_step = T-1` (logits always from the last loop; all T loops always run), bf16, eval mode, SDPA attention and the fast KV cache.
  - Never call the model with the default early-exit threshold.
- Neuron hooks: `loopneuron.hooks`. One forward pre-hook per `layers[l].mlp.down_proj`. The loop index is the per-layer call counter modulo T. The counters reset when a `with NeuronHooks(...)` block is entered (there is no `reset()` method), so use a fresh block per measurement; every forward calls each `down_proj` exactly T times, so many forwards (e.g. `generate`) can share one block.
- GPU is 8 GB. Never load Ouro and the Qwen GGUF server at the same time.
- Disk: the full run needs ~17 GB (venv, two Ouro checkpoints, GGUF, llama.cpp). `load_model` calls `config.disk_guard()` with `MIN_FREE_GB` before downloading uncached Ouro weights; call it yourself before adding any other large download.
- Statistics: confirmatory data (`data/prompts/confirm.jsonl`) must never be used for selection or tuning. Pre-registration lives in `reports/preregistration.md`. Never edit it (`confirm_steering` checks it is committed and unchanged). It and `results/Ouro-1.4B/candidates.json` contain hand-added parts that `prereg.py` does not write (the exploratory unit L19 N3901 and the amendment log); re-running `preregister` would drop the exploratory unit.
- Logging: use `loopneuron.logging_utils.get_logger`. LLM prompts and outputs must be logged in full.
- Tests: `uv run pytest -q`. GPU tests are marked `gpu`.
- Phases, in order: setup_check → build_atlas → screen_candidates → validate_candidates → label_candidates → preregister → (commit + push the pre-registration) → confirm_steering → followups → llm_judge → audit → extras → replicate → replicate_fresh → report → publish.
- On Windows, run phases with `uv run --no-sync` while another `uv run` process is active. A rebuild of the local package can hit a transient file lock.
- Report numbers must come from `results/Ouro-1.4B/*.json`. Tables in `reports/tables/` are generated by `loopneuron.reporting`; regenerate them without loading a model with `write_tables(Path("results/Ouro-1.4B"), Path("reports/tables"))`.
